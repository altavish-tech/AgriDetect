📋 Quick Start Guide

  1. Frontend: Open http://localhost:3001/ in your browser
  2. Select Role: Choose Farmer, Expert, or District Officer
  3. Test Workflow: Try the complete flow from photo upload to advisory
  4. Backend API: Available at http://localhost:5000/api
⚠️ Troubleshooting:
  • If you see "Cannot GET /", try opening the full URL with trailing slash
  • Clear browser cache or try incognito/private mode
  • Make sure both servers are running (check terminal outputs)
  • Try a different browser (Chrome, Firefox, Edge)
